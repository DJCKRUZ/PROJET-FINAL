# Spécification courte — Explorateur de Films

But
- Permettre à l'utilisateur de parcourir et rechercher des films via une interface simple et responsive.

Cas d'utilisation
- Voir une grille de films populaires (échantillons fournis)
- Rechercher par titre
- Ouvrir un film pour voir le résumé et les métadonnées

Comportement
- Sans clé API: recherche filtre les films d'exemple locaux
- Avec clé TMDB: recherche réelle contre l'API TMDB et affiche les affiches réelles

Contraintes
- Page statique, pas de backend requis
- Déploiement prévu sur GitHub Pages
